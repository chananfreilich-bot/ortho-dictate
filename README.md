# Ortho Dictate

Orthodontic voice dictation for Smilecloud (consult, recall, adjustment, bonding, repositioning, appliance delivery/removal, debond templates).

## Install or update on any computer
1. Install **Tampermonkey** in Chrome and turn on **Allow User Scripts** (chrome://extensions → Tampermonkey → Details).
2. Open this link and click **Install** (or **Update** / **Reinstall**):
   **https://raw.githubusercontent.com/chananfreilich-bot/ortho-dictate/main/ortho-dictate-smilecloud.user.js**
3. Refresh Smilecloud. The panel header shows the version.

New versions posted here are picked up by Tampermonkey automatically.

`OrthoDictate.html` is the stand-alone version (download, open in Chrome, copy/paste the note).
See `SETUP.md` for dictation tips.
